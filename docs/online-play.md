# 宝可梦联机与自部署

## 运行方式

本项目仅提供宝可梦游戏代码，不提供公共联机服务器。联机需要部署者使用自己的 Cloudflare 账号运行静态前端、Worker 和 SQLite Durable Objects。

需要 Node.js 22 或以上，首次运行 `npm ci`。

- `npm run start:local`：纯静态服务，打开 `http://127.0.0.1:4174/?mode=local` 本地同机体验。
- `npm start`：构建前端并运行本地 Worker，打开 `http://127.0.0.1:4174/` 测试联机准备室。
- `pokemon.html` 与根入口均可使用，`?mode=local` 明确选择本地体验。

两个服务共用 4174 端口，不要同时启动。`127.0.0.1` 只用于本机；跨设备邀请应使用正式部署后的 HTTPS 地址。同机多玩家测试应使用独立浏览器或浏览器配置，普通新标签页会共享席位。

创建房间 → 复制邀请 → 朋友加入 → 全员准备 → 房主开局。支持 2–4 人。邀请只带房间 ID，不含席位凭证；持有链接的人可在满员或开局前加入，没有额外房间密码。

## 部署到自己的 Cloudflare

1. 准备自己的账号；将根目录 `wrangler.jsonc` 中的 `name` 改为自己的 Worker 名称。
2. 使用 `npx wrangler login` 正常登录；有多个账号时，可在配置中明确填写自己的 `account_id`。
3. 运行 `npm test` 和 `npm run check:deploy`。
4. 运行 `npm run deploy`，打开命令返回的 HTTPS 地址。

仓库默认未填写个人账号或自定义域名，使用平台分配的 workers.dev 地址。如需自定义域名，应在自己的账号中配置。不要提交 API Token 或登录凭证。

部署包只包含 `src/` 和 `assets/source-cards/`。构建会清理项目生成的 `dist/`，不会上传测试、日志、Git 元数据或 `.wrangler/` 的本机状态。

Worker 的 `/` 路径映射到 `index.html`，`/api/*` 交给房间服务，其他文件由 ASSETS 提供。仅上传 HTML、CSS 和图片到静态托管，不足以运行联机服务。

## 同步与隐私

- 每个房间对应一个 Durable Object；服务器洗牌并调用原规则引擎完成操作。
- 客户端通过同源 HTTP 提交动作，Authorization 中带私密凭证；WebSocket 首条消息验证凭证，不将凭证放在 WebSocket URL 中。
- 预留卡详情仅发送给所属席位；其他人只收到数量。牌堆只发送数量，不暴露顺序或卡牌标识。
- 服务端验证行动席位、参数和修订号。状态与最近 128 条成功回执一同持久化；网络结果不确定时使用同一操作编号重试，避免重复执行。
- 重复成功操作直接返回当前视图，不再次写存储或广播。

## 断线与房间生命周期

- 同一席位只保留一个实时连接，新页面接管后旧页面停止自动争抢。刷新可通过当前浏览器保存的凭证恢复原席位。
- 每轮最多自动重试 8 次，间隔为 1、2、4、8、16、30、30、30 秒。耗尽后等待玩家点击“重新连接”。稳定连接满 60 秒且无待确认操作后重置次数。
- 浏览器报告离线时停止自动请求并取消在途请求；网络恢复后手动重连。身份失效或限流时也会暂停。
- 断线不代打、不自动判负、不结束回合；轮到离线玩家时需要等待其恢复。
- “切换房间”保留原房间凭证；准备室“退出房间”释放席位。开局后禁止释放席位，结算后房主可返回准备室。
- 连续 7 天无房间变更或成功操作会过期清理，单纯连接或读取不续期。
- 没有账号登录或跨设备找回；清除站点数据、更换浏览器或域名不会自动迁移原席位。

## 验证与边界

```sh
npm test
npm run check:deploy
# 本地联机服务运行时：
npm run test:online
```

测试覆盖身份、回合、重连预算、重复与过期命令、隐藏视图、昵称转义、双客户端同步与并发提交。真实双客户端脚本只允许访问本机，不会对公网房间进行压力测试。

适用于好友邀请对局，不包含公开匹配、账号找回、聊天、观战、付费或排行榜。面向大量玩家开放前，请自行配置入口限流及用量监控；重试保护不能保证免费额度永不耗尽。

参考：[WebSocket Hibernation](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)、[Static Assets binding](https://developers.cloudflare.com/workers/static-assets/binding/)。
