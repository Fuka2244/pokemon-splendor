# Rare, legendary, and evolution actions

稀有宝可梦和传说宝可梦分属两个公共牌堆，桌面同时尽量公开一张稀有和一张传说；捕捉其中任一张都是独立主要行动，满足永久折扣条件即可获得。若卡面要求万能球，万能球是捕捉成本并会被支付回供应区；其他球图标表示永久折扣条件，不消耗手中精灵球。主要行动完成后再检查可选进化；进化需要满足永久折扣条件，并且目标进化宝可梦已出现在野外区域或当前训练家的预留区，随后目标牌替换原已捕捉牌而不是叠加成第二张普通牌。

终局同分时比较所有已获得宝可梦总数，普通、稀有和传说都计入数量，数量更少者优先；进化替换前后仍只算一张。

普通宝可梦卡始终只提供其属性1点永久折扣。稀有和传说宝可梦可以按卡面效果提供分数或特殊永久折扣；这些特殊永久折扣可以降低后续普通牌捕捉费用，也可以用于进化条件和稀有／传说捕捉条件，但不会增加普通牌张数。
