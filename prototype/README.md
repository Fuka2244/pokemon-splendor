# 宝可梦璀璨宝石交互原型

> THROWAWAY PROTOTYPE：用于回答“哪种 BGA 风格桌面布局最适合这个游戏？”，不是生产代码。

启动：

```powershell
npm run prototype
```

然后打开：

- `http://127.0.0.1:4173/?variant=A` — BGA 桌面布局
- `http://127.0.0.1:4173/?variant=B` — 卡牌焦点布局
- `http://127.0.0.1:4173/?variant=C` — 移动端引导布局

页面底部或键盘左右方向键可以切换布局。点击精灵球、卡牌、捕捉和预留按钮，可以体验一回合中的主要反馈。
